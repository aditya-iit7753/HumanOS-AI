# What The Buyer Gets

## Product
The buyer receives HumanOS AI as a white-label full-stack AI SaaS platform.

## Included
- Full source code
- Frontend app
- Backend API
- PostgreSQL schema
- SQLAlchemy models
- API routes
- Clerk authentication flow
- AI chat assistant
- Long-term memory system
- Task management
- Goal tracking
- Career Copilot
- Document Copilot
- Agent system
- Daily planner
- Settings page
- Pricing UI
- Docker Compose setup
- Vercel deployment config
- Railway deployment config
- Environment variable guide
- README setup documentation

## White-Label Rights
Buyer can rename the product, add logo, change colors/copy, use own domain, deploy on own infrastructure, add own API keys, modify the codebase, and build a commercial SaaS from it.

## Buyer Must Provide
- OpenAI API key and billing
- Clerk account and keys
- PostgreSQL database
- Qdrant vector database
- Vercel/Railway or equivalent hosting
- Payment gateway keys if enabling payments
- Domain name
- Branding assets

## Suggested Delivery
- Private GitHub repository transfer or ZIP handover
- 1 setup call
- Environment variable setup guide
- Deployment walkthrough
- 30 days bug support

## Not Included By Default
- Buyer cloud hosting fees
- Third-party API fees
- Custom feature development beyond agreed scope
- Marketplace submission
- Ongoing maintenance after support period

## Recommended License Language
Buyer receives a commercial white-label license to deploy, modify, and operate HumanOS AI for their own business. Resale or redistribution of the raw source code to third parties requires a separate agreement.
