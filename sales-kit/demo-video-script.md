# 2-Minute Demo Video Script - HumanOS AI

## Goal
Show HumanOS AI as a complete white-label AI SaaS platform that a company can buy, deploy, brand, and sell as its own product.

## Video Length
Target: 2 minutes

## Script

### 0:00 - 0:10 - Opening
Visual: Landing page hero and app logo.

Voiceover:
"This is HumanOS AI, a white-label AI operating system for life, career, productivity, documents, goals, agents, and learning. It is built as a complete SaaS foundation that companies can deploy with their own brand, domain, API keys, and customer base."

### 0:10 - 0:25 - Dashboard
Visual: Login, then dashboard cards.

Voiceover:
"After login, users get a premium dashboard that connects AI chat, memory, tasks, goals, career tools, documents, agents, and a daily planner in one workspace."

### 0:25 - 0:45 - AI Chat and Memory
Visual: Chat page, ask a career/productivity question, show streaming answer.

Voiceover:
"The AI assistant supports streaming answers and long-term context. It can use saved memories, goals, tasks, and user preferences to provide more personalized guidance over time."

### 0:45 - 1:05 - Productivity System
Visual: Tasks, goals, planner.

Voiceover:
"HumanOS includes task management, long-term goals, milestones, AI roadmaps, and a daily planner that converts user priorities into time-blocked execution plans."

### 1:05 - 1:25 - Career and Documents
Visual: Career Copilot and Document Copilot pages.

Voiceover:
"For career-focused businesses, HumanOS includes resume generation, ATS scoring, skill gap analysis, interview questions, role recommendations, and document AI for summaries, notes, Q&A, and action items."

### 1:25 - 1:45 - Agents
Visual: Agents page and one agent detail page.

Voiceover:
"The platform also includes specialized agents for career, study, research, productivity, and documents. Each agent can generate action plans and save outputs to the database."

### 1:45 - 2:00 - White-Label Offer
Visual: Settings, branding mockup, architecture slide.

Voiceover:
"Companies can buy the full source code, deploy it on their own infrastructure, connect their own OpenAI, Clerk, database, vector database, and payment provider, then launch it as their own AI SaaS product. HumanOS AI can save months of engineering work."

## Screen Recording Checklist

- Landing page hero
- Sign in/sign up
- Dashboard
- AI Chat response
- Memory page
- Tasks page
- Goals page
- Career Copilot
- Document Copilot
- Agents page
- Planner page
- Settings page
- Pricing page

## Editing Notes

- Use calm premium music.
- Keep cuts fast and clean.
- Add captions for each module.
- End with: "White-label AI SaaS platform - available for acquisition/licensing."
