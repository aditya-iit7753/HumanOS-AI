# HumanOS AI Sales Kit

This folder contains the buyer-facing sales material for selling HumanOS AI as a white-label AI SaaS platform.

Recommended selling position:

HumanOS AI is a white-label AI operating system for life, career, productivity, documents, goals, agents, and learning. Companies can deploy it on their own cloud, use their own API keys, connect their own domain, customize branding, and extend modules for their market.

Core offer:

- White-label source license: Rs. 5,00,000
- White-label + deployment support: Rs. 7,50,000
- Enterprise customization package: Rs. 10,00,000+

Use these files:

- `demo-video-script.md` - 2-minute demo video script and shot list
- `pitch-deck.md` - investor/buyer pitch deck content
- `feature-list.md` - complete product feature list
- `architecture.md` - technical architecture diagram and stack
- `buyer-gets.md` - buyer handover/scope document
- `pricing-proposal.md` - pricing and proposal document
- `outreach-message.md` - LinkedIn/email message templates
- `screenshots-checklist.md` - exact screenshots to capture

PDF exports are generated in `output/pdf/`.
