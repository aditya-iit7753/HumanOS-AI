## Recommended Sizes
- Desktop: 1440 x 900
- Mobile: 390 x 844

## Screenshot Tips
- Use dark mode for premium visual appeal.
- Use sample data before screenshots.
- Avoid showing private API keys, emails, or real user data.
- Use the stable demo URL.
- Crop browser chrome only if needed.
